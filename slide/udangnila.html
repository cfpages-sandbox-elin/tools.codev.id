Playbook: Live TikTok Fokus Akuisisi

  • Live pagi: bukti kulak subuh di tambak (segar, bukan stok lama).
  • Live sortir: grading + timbang live + lelang size.
  • Live sore: flash sale sisa stok, harga coret, stok terbatas.
  • Peran: 1 host + 1 admin komen/rekap + packing standby.
  • Order: komen MAU + kg → bayar QRIS dulu → kirim batch sore.
  • Jadwal: 3-4x/minggu, 30-45 mnt. Target 15-25 kg/live, konversi >50%.

Setup HP + tripod + ring light + mic clip-on +-Rp200-300rb. Syarat akun: TikTok + TikTok Shop (KTP, rekening).

Produk: Grading Udang dan Nila

  • Vaname size 40 / 60 / 100: angka = ekor per kg. Makin kecil makin besar.
  • Nila 300-500 g/ekor: 2-4 ekor/kg, disiangi bersih.
  • Bentuk jual: segar-es dan bersih beku 500 g / 1 kg.
  • Susut: cuci + siangi +-5-10%. Nila rendemen bersih 88-92%.

Operasional: SOP Dingin + Biaya Es

  • Kulak 04.30-06.30, es 1:1 (1 kg es per 1 kg ikan).
  • Cuci 2x air es, timbang, packing, label tanggal.
  • Freezer -18°C, FIFO, kirim <2 jam styrofoam + es.

Risiko dan Mitigasi

  • Harga tambak fluktuatif → aturan batas kulak slide 14.
  • Tidak habis → bekukan, olahan, flash sale sore.
  • Live sepi → jadikan konten recorded, konsisten.
  • Order fiktif → wajib bayar dulu.
  • Listrik mati → es cadangan + jual segar dulu.
  • Kas campur → pisah dompet usaha.

Ide Pengembangan Berikutnya

  • Paket langganan mingguan + nila fillet/ungkep frozen + udang kupas.
  • Limbah jeroan → pakan lele/taman. NIB + label halal/PIRT bila masuk ritel.
  • Pembukuan WA + sheet sederhana + foto/video proses sebagai bukti bersih.

Keputusan dan Larangan

Jangan jual tanah / pinjam bank sebelum Fase 1 lolos. Pinjam bank / jual tanah hanya Fase 2 bila validasi lolos.

  • Layak naik fase: habis 2 minggu + repeat >30% + kas pisah + freezer stabil.
  • Butuh persetujuan keluarga untuk tiap tambah modal >Rp5 jt.
